Atoms — a nano sandbox

Interactive molecular dynamics: gas, liquid, crystal, phase transitions and chemical reactions emerge from interaction potentials and conservation laws, not from prepared scripts. Next to them are worlds of other scales: nuclei and chain reactions, quarks, semiconductor devices and the electron wave. This manual describes version 5.0.

This manual uses the labels of the English interface. The program is also fully available in Russian: the RU | EN buttons in the top bar or Ctrl+L switch the language (see Interface language); the Russian manual is ИНСТРУКЦИЯ.html. Every button, slider and atom also shows a tooltip on hover.

Quick start

  • Tab — scene menu. Pick any scene: it starts right away.
  • Space — pause, R — reset the scene, Ctrl+LMB — rotate the camera.
  • E — periodic table: pick an element, then LMB in the scene to add atoms. F7 — atom structure: electron clouds and orbitals.
  • LMB on an atom — "tweezers". RMB — heat, Shift+RMB — cool, wheel — zoom.
  • H — a short key cheat sheet inside the program, F1 — the full manual in the interface language (this file when the interface is English).
  • Ctrl+L or the RU | EN buttons — switch the interface language instantly.
  • Hover over any button, slider or atom to see a tooltip.

Installing and removing

  • The installer AtomsSetup.exe is a single file with the program, both manuals, the license and the OpenMP runtime inside. By default it installs for the current user into %LOCALAPPDATA%\Programs\Atoms — no administrator rights needed. Browse… picks another folder; the check boxes are a desktop shortcut, a Start menu shortcut and running the program when done. Installing again updates the program in the same folder.
  • The program keeps its settings and quick save next to itself, so it is best installed where you can write without administrator rights. If you pick, say, Program Files, the installer warns you and asks for the rights.
  • Removing — from the list of installed apps in Windows or with uninstall.exe in the program folder. It removes the program, its settings, the shortcuts and the entry in the list; your own files (quick save, snapshots, CSV) stay, and then the folder stays too.
  • Switches for unattended installs: /S — no window, /D=folder, /nodesktop, /nostartmenu, /norun, /lang=ru|en; uninstall.exe /S removes without questions.
  • Without installing: unzip atoms-windows-x64.zip into any folder and run atoms.exe from there.

Colors

The interface is monochrome: panels, buttons, text, plots, the grid, toasts and field objects use shades of gray only, so that color always means something about the atoms.

  • Atoms keep their colors: element (CPK) colors and every coloring mode (C) — element, speed, energy, order, coordination, phase. The legend in the scene corner, the palette swatches, the phase fraction bar in the readings and the color square on the element card are colored too, so every atom color can be read off.
  • Plot series are told apart by line style — solid, dashed, dotted, dash-dot — and brightness; each legend shows a sample of the line.
  • Warnings appear on a light plate (e.g. energy drift above 0.2 %, a reduced time step, capped forces); a stability alert is a white-text line marked with a white bar. Errors are inverted: a white plate with black text (e.g. energy drift above 1 %).
  • An active or selected control has a white frame. Heat and energy release are drawn bright and solid; cold and absorption dim and dashed. Partial charges (charges on the Control tab): + — a bright solid ring, − — a gray dashed ring.

Interface language

  • The interface is available in English and Russian. The RU | EN buttons in the top bar or Ctrl+L switch the language instantly, without a restart: labels, tooltips, toasts, scene titles and the cheat sheet all change.
  • The choice is saved in atoms.ini next to atoms.exe. On the first start the language follows the Windows UI language.
  • Command line: atoms.exe --lang en or --lang ru sets the language for that run (it takes priority over atoms.ini and is not saved).
  • F1 opens MANUAL.html when the interface is English and ИНСТРУКЦИЯ.html when it is Russian (if one file is missing, the other one opens).
  • CSV export follows the language: English uses a comma separator and a decimal point, Russian a semicolon and a decimal comma (for Excel with a Russian locale). Column headers are in the interface language.

Selection and measurements

  • Box — select, Shift — add to the selection, Ctrl+A — everything. Clicking an atom selects its whole molecule.
  • Drag the selection — move it; Alt+drag — "throw" (set a velocity); Alt+wheel — rotate.
  • Del — delete, Ctrl+C / Ctrl+V / Ctrl+X — copy / paste at the cursor / cut.
  • I — pin/unpin: pinned atoms stay still (a substrate, a clamp, an "anchor") and do not count toward the temperature.
  • The Object tab: composition, T (excl. CM), center of mass, momentum |p|, mass; buttons pin/unpin, stop, heat ×1.5 T, cool ×0.67 T, element → X (X is the current palette substance), delete, copy, paste, rotate −15° / rotate +15°, follow, deselect.
  • Moving, rotating, pasting and changing the element are refused if atoms would overlap, so the sandbox does not "explode". element → X checks this after the replacement: if the new atoms would overlap their neighbors, the change cancels itself and a toast says so.
  • Ruler (Alt+3): the Measurement block on the Object tab shows distance 1–2, angle 1–2–3 and the dihedral angle.

The Scene tab: an editor

  • Boundaries per axis. The x/y/z periodic check boxes: on a periodic axis an atom leaving on one side comes in on the other; otherwise the axis has two walls. This gives a film (x and z periodic, walls at the top and bottom), a channel or a closed box. When an axis turns into walls, molecules cut by the boundary are put back together, and those that end up right against a new wall are removed (a toast tells how many) — otherwise the wall would push them out with a huge energy.
  • The kind of each wall. Clicking a face row (x− left … z+ front) cycles the kinds: normal — attraction set by the wall wetting slider; sticky — strong attraction (adsorption, films); thermal — a reflected atom gets a velocity at the wall temperature (each face has its own slider); absorbing — a molecule that hits it disappears, as in pumping, and a counter shows how many atoms were taken; mirror — elastic reflection without attraction. Special faces are visible in the scene: sticky is filled, thermal is brighter the hotter it is (a cold one is dashed), absorbing is hatched, mirror has highlights; the kind is labeled in the middle of the face.
  • Vessel — the box, a sphere or a cylinder along y inscribed in the box; its wall behaves as a normal face. Molecules outside are removed. A vessel is not available with a piston, and compressing along x ([ ]) works only without a vessel.
  • Grid placement. The exactly on grid check box: the Add tool puts one molecule of the selected substance (or a library structure) at a grid node on the horizontal working plane; a translucent "ghost" shows where it will go. Shift+drag lays a row of molecules in every node along the way. The sliders set the grid step and the height of the working plane.
  • Fill a region: the whole vessel, the left/right/lower/upper half, a sphere in the center or a layer at the floor — with a given density (molecules per nm³: gas at 1 atm — 0.025, liquid water — 33) and temperature. clear region removes every molecule from it.
  • All of this is saved with the scene (Ctrl+S, F5) and can be undone with Ctrl+Z.

Camera

  • F/Home — fit the box, O — auto-rotation, F2 front, F3 side, F4 top, F6 isometric.
  • V — fly mode: WASD, Q/E — down/up, Shift — faster.
  • X — cross-section, Shift+wheel — position of the cutting plane.

Physics

Model

  • Energies on the real scale: 1 eV = 83.0ε; bond energies and charges are not scaled down, so the temperatures in the scenes are real: water at 300 K, combustion up to thousands of kelvins.
  • Van der Waals — the Lennard-Jones potential (Lorentz–Berthelot rules), shifted cutoff.
  • Electrostatics — full Coulomb by the damped shifted force method (DSF: α = 0.23 Å⁻¹, cutoff 9.5 Å) from a spline table; charged fragments also get their self-energy. Partial charges come from electronegativities, ions use Joung–Cheatham parameters.
  • Water — a flexible SPC/Fw-type model: at 300 K its density is 0.96 g/cm³ and its diffusion coefficient 2.5·10⁻⁹ m²/s (real water: 0.997 and 2.3·10⁻⁹); check it with --water.
  • Covalent bonds — the Morse potential with a soft core: reference energies and lengths, stiffness from molecular vibration frequencies. Multiple bonds, bond angles from VSEPR domains (lone pairs push bonds harder than bonds push each other), π torsion: a double bond resists twisting.
  • Hydrogen bonds — there is no separate term, as in the SPC and TIP water models: they are held by the attraction of the partial charges of H⁺ and O⁻, N⁻, F⁻, Cl⁻, while the bare core of hydrogen keeps a proton from sliding over to a foreign oxygen.
  • Metals — the many-body second-moment potential (Gupta / Cleri–Rosato): a bond depends on the number of neighbors, so surfaces, melting and nanoparticle faceting are realistic.
  • Integrator — velocity Verlet with an automatic time step; fast bond and angle vibrations run in inner steps (RESPA), slow forces once per outer step. The step is fitted to the state of a scene right away and grows back carefully after shrinking, so even a flame at 3500 K loses no more than hundredths of a percent of its energy over picoseconds. Verlet neighbor list, OpenMP. Forces are checked against numerical differentiation of the energy (--gradcheck).
  • Initial velocities of molecules are in thermal equilibrium from the start: velocities are split into translation, rotation and vibration, and the vibrations get their share of energy (at equilibrium the kinetic energy of a vibration equals its potential energy). Otherwise the vibrations would hand half of their energy over to potential energy, and in a gas hydrogen would stay colder than its neighbors.
  • The average shape of molecules on screen. Bonds to hydrogen vibrate in 10–30 fs, faster than a frame: taken with such an exposure, H atoms would dart about from frame to frame. In nature these vibrations are "invisible" at room temperature — their quantum ħω is 7–17 times larger than kT, and the molecule sits in its vibrational ground state. So the shape of each molecule averaged over about 60 fs is drawn, while its translation and rotation are shown without delay. The simulation does not change; it can be turned off in the settings. Check the smoothness with --jitter.

Units

Lengths and temperatures are calibrated to argon: σ = 0.3405 nm, mass 10 u, ε/k = 139.8 K — so the model's critical point (T*c = 1.078) matches argon at 150.7 K, the triple point comes out at ≈ 87 K (argon: 83.8 K), time τ = 0.999 ps, pressure ε/σ³ = 482.5 atm. Chemical energies: 1 eV = 83.0ε. The program shows both model and real quantities everywhere.

Thermostats and barostat

  • NVE — an isolated system, energy is conserved.
  • Bussi (CSVR) and Langevin — a correct canonical ensemble; Nosé–Hoover — deterministic; Berendsen — fast, gentle approach to T; power heating — constant power (for the melting plateau, set with the heating power slider).
  • NPT barostat (C-rescale) on the Physics tab (Bernetti–Bussi): the box "breathes" toward the set pressure P* external with correct volume fluctuations. Periodic boundaries only; with walls there is a piston.
  • Pressure comes from the virial theorem with all contributions (pair, many-body, bonds, angles).

External influences

gravity g, electric field E along x (field E and current I in the readings), Thermal walls (hot left / cold right, or a hot bottom), wall wetting, field objects, tools.

Stability guard

The program keeps two state snapshots (every 200 steps). If non-finite numbers appear or the temperature "explodes" with a broken energy balance, it rolls back to a snapshot, reduces the step and continues. An alert line in the readings, marked with a white bar, reports this; the Integration stability block on the Physics tab counts the rollbacks.

States of matter

  • Each atom gets a phase — gas, liquid, solid — from its local structure (Steinhardt order parameters), number of neighbors and mobility. The phase coloring mode (C) colors atoms by it.
  • The readings show a phase fraction bar (in the phase colors) and a description of the state ("melting: crystal + liquid", "evaporation: liquid + vapor" and so on).
  • The Physics tab: a mini T–ρ phase diagram of the model with the trace of your state. Solid gray line — the liquid–vapor binodal, white dashed — melting/freezing, fine dots — the triple line, C — the critical point; a white square with a dot is the current state and a light line its path. Below it: State of matter, the Transition log (melting, crystallization, boiling, condensation, sublimation) with temperature and time, and the heat of transition from the T plateau.
  • The order coloring mode shows the lattice: FCC, HCP, BCC, SC/NaCl, ice.
Try this: scene 2 → thermostat power heating → watch the T(t) plateau on the Plots tab and the transition log. Then place a cooler (Alt+F) and watch crystallization start from the cold zone.

Chemistry

How reactions happen

Chemistry here is not an animation but events within the same molecular dynamics: a bond forms when atoms come close and have a free valence; it breaks when overstretched; an atom switches to another partner (exchange) if the barrier is overcome. The energy of each event is computed exactly: reaction heat goes into atomic motion, so combustion heats the mixture by itself, and endothermic reactions cool it.

  • Bond energies and lengths — real tabulated values for the common pairs and bond orders (H–H 4.52 eV, O=O 5.12, N≡N 9.79, C–H 4.3, O–H 4.8…). Halogens, sulfur, phosphorus, silicon, boron and interhalogen pairs (H–F, N–F, P–F, Si–F, B–F, S–Cl, B–Cl, Cl–F, I–Cl, H–Se, H–Ge, H–As and others, about 70 pairs in all) also come from reference tables; the remaining pairs follow Pauling's rules from electronegativities. The scale is real: 1 eV = 83ε.
  • Valence is counted by electrons: an atom has valence electrons, lone pairs and a formal charge. Sulfur, phosphorus, chlorine, bromine, iodine and xenon next to electronegative neighbors (F, O, Cl) can become hypervalent: SO₂, SO₃, H₂SO₄, H₃PO₄, HClO₄, SF₄, SF₆, PF₅, PCl₅, ClF₃, BrF₅, IF₅, XeF₂, XeF₄, XeO₃ — up to six bonds per atom. The shape of a molecule is set by VSEPR domains, lone pairs included: bent SO₂, the SF₄ "seesaw", T-shaped ClF₃, square-planar XeF₄.
  • Barriers follow Marcus: E = E₀(1 + ΔH/4E₀)², where E₀ is the intrinsic barrier of the reaction (atom exchange, addition to a multiple bond, radical association) and ΔH its heat. A strongly exothermic reaction runs without a barrier, a strongly endothermic one needs at least ΔH. The reaction barriers × slider multiplies E₀ — it changes the kinetics without touching the equilibrium.
  • Orbitals — a bond forms only if the atoms meet along a free orbital (see Orbitals in molecules). So not every collision with enough energy reacts, only a well-aimed one — this is the steric factor known from experiment.
  • Charges — partial, from electronegativity differences; for ions (H₃O⁺, OH⁻, NH₄⁺, SO₄²⁻…) the charge is distributed by atomic hardness (a simplified electronegativity equalization).
  • Acids and bases — proton transfer: HCl + H₂O → H₃O⁺ + Cl⁻, H⁺ hopping along a chain of water molecules (Grotthuss), neutralization H₃O⁺ + OH⁻ → 2H₂O, NH₃ + H₃O⁺ → NH₄⁺. The water around new ions does not rearrange instantly: the energy of this rearrangement is "borrowed" and paid back as it happens. Water autoionization is not modeled: in a box of ~10⁻²³ L its equilibrium is zero ions.
  • Catalysis — a catalyst zone (K; barriers ×0.25) and the surface of metals Pt, Pd, Ni, Fe, Cu, Ru, Rh, Ag…: molecules that touch the metal split into atoms, the atoms settle on the surface and assemble into new molecules there (the Langmuir–Hinshelwood mechanism).
  • Metals with non-metals — oxides and salts through ionic-covalent bonds; an oxidized atom loses its metallic bonding. An atom's oxidation state is shown on the Chemistry tab (Atom: charges and oxidation) on hover.
  • Light (L) — photodissociation by quanta with the wavelength set on the Chemistry tab; see Light and photons.

The Chemistry tab

  • Reactions: switches chemical reactions, acids and bases, metal surface catalysis, bonds only along orbitals (turn it off and a bond forms on any approach of the atoms, so reactions run faster), catalyst zone, the reaction barriers × slider, event and heat counters.

The model is simplified: atoms move classically, there is one bond curve per atom pair, and electron transfer is not modeled explicitly (redox goes through bonds). The simulation covers picoseconds, so reactions that are slow at room temperature run in the scenes at high temperatures, from a spark or from light.

Orbitals in molecules

The valence electrons of an atom in a molecule occupy "clouds" — hybrid orbitals: one for each bond (σ), each lone pair and an unpaired electron. The clouds spread as far from each other as they can (VSEPR theory): two along a line (sp), three in a triangle (sp²), four as a tetrahedron (sp³). Bonds point at the neighbors, the other clouds into free directions. The directions follow the current positions of the atoms, so the clouds turn together with the molecule.

  • The orbitals layer — Shift+O or the checkbox in the Display block of the Control tab. Lone pairs are blue lobes with two dots (two electrons), an unpaired electron is an amber lobe with one dot, the π clouds of multiple bonds are green, above and below the bond (a triple bond has two clouds crosswise). In a planar radical (CH₃·) the unpaired electron sits in a p orbital across the plane — two lobes. A lone atom is surrounded by a spherical cloud: amber if it has unpaired electrons (H, O, Cl atoms are radicals), blue if all its electrons are paired (the Cl⁻ ion).
  • Orbitals decide whether a bond forms. The partners have to meet along a free orbital, within a ±60° cone around its axis:
    • a radical takes an atom along the axis of its free orbital — a planar CH₃ along the axis of its p orbital, from above or below;
    • in an atom transfer (Cl + CH₄ → HCl + CH₃) the attacker approaches the transferred atom from behind, along the line of the bond being broken — the Cl···H···C transition state is almost straight;
    • a radical adds to a double bond from the side, through the π cloud, not along the bond axis;
    • a proton lands on a lone pair of the base — in water it points away from the hydrogen atoms.
    So only a well-aimed collision reacts — this is the steric factor of reactions. For an atom with one bond and several free clouds (OH·, Cl in Cl₂) the clouds merge into a "cap", and the whole back side of the atom will do; a lone atom accepts a bond from any side.
  • The rule is switched off with the bonds only along orbitals checkbox on the Chemistry tab: then a bond forms on any approach and reactions run faster — you can compare.
Try this: "Methane combustion" → Shift+O. O₂ molecules show π clouds and lone pairs, while the O, H, OH and CH₃ radicals that appear after the spark show the amber clouds of unpaired electrons. The next reactions of the chain run exactly on them.

Light and photons

The L key flashes light along the ray under the cursor (as wide as the brush). Light consists of quanta with energy hν = hc/λ; the wavelength λ is set on the Chemistry tab (the Light section, 100 to 1000 nm), next to the photon energy in eV and the name of the band: vacuum UV, UV-C/B/A, the colors of visible light, infrared.

  • A quantum breaks a bond only if it is enough both to break it (hν ≥ D, the bond energy) and to be absorbed: the molecule has to absorb light of this frequency. For halogens the absorption band starts right at the bond energy, while most molecules absorb only far in the ultraviolet. Light shorter than this splits: I₂ 805 nm, Br₂ 630, Cl₂ 495, F₂ 400, H₂O₂ 300, O₂ 243, H₂O 177, CH₄ 144, H₂ 112 nm.
  • So red light will not split Cl₂ however long it shines, while blue light will: frequency matters, not brightness, as with the photoelectric threshold. If nothing under the cursor absorbs this light, a toast says it passed through and what energy it would take.
  • The photon energy goes into the fragments flying apart along the bond axis (the translational part is at most D + 1 eV; the rest is carried away by excited fragments and their glow) and is counted as external work.
  • The default λ = 122 nm is the Lyman-alpha line of a hydrogen lamp: it breaks almost everything except H₂ and N₂, so L ignites the mixture in the combustion scenes.
  • Check it with --lighttest: CH₄ + Cl₂ and H₂ + O₂ mixtures under flashes of different wavelengths.

Atom structure

F7 (or the button on the cloud thumbnail in the atom card) opens the Atom structure window. The element is the one of the atom under the cursor; inside the window the ◀ ▶ arrows and element from the table (E) change it.

  • The cloud is drawn as a glowing gas: ψ is computed at the nodes of a volume grid, and rays pass through it — each one collects the glow and loses brightness in dense places. The picture is computed by the processor and updated as it turns.
  • atom cloud — all electrons; a quarter of the atom is cut away, and the cut shows the layers of the shells (s red, p orange, d blue, f green) and the dark nodes of the wave between them. The brightness is the probability of finding a shell's electron at this distance from the nucleus (r²|ψ|²), as on the radial plot on the right. The electron does not fly along an orbit: it is a standing wave, and the cloud shows where it can be found.
  • orbital — one orbital n, l, m: the cloud glows where |ψ|² is large, the color is the sign of ψ (orange plus, blue minus), and a glossy surface encloses the region where the electron is found 85% of the time; the corner shows the angular part |Y|; under the buttons — the number of electrons in the orbital (0, 1 or 2 — the Pauli principle).
  • s p d f shapes — the angular parts of all orbitals as smooth glossy figures: one s, three p, five d, seven f; the shade of a lobe is the sign of the wave function.
  • On the right — the electron configuration, the subshells with their electron counts, the effective nuclear charge Z_eff (Slater's rules) and the mean radius, and the plot "where the electrons are: probability at distance r".
  • The cloud can be rotated with the mouse. The radial functions are hydrogen-like with Z_eff, so sizes are approximate while shapes are exact.

Worlds of other scales

The last four sections of the scene menu are not molecular dynamics but models of other scales. Each world has its own panel on the right: readings, restart (R), pause (space), the time speed slider (how much world time passes per second on screen), the device sliders, a plot and an explanation. In these worlds the mouse controls the camera (in the quantum scenes a click on the wave is a measurement). The color legend is under the scene.

Nuclei

  • Half-life — nuclei decay at random, yet their number falls exactly as N₀·2−t/T½; isotopes with real half-lives (NUBASE 2020): I-131, Cs-137, C-14, Co-60, F-18, radon, polonium, radium, uranium-238. You see alpha particles, β⁻ electrons, β⁺ positrons, gamma quanta and antineutrinos.
  • Radon decay chain — Rn-222 → Po-218 → … → Pb-206; periods from 164 μs (Po-214) to 22 years (Pb-210), where the chain "gets stuck".
  • Critical mass — a uranium-235 sphere and Monte Carlo neutron transport with real cross sections: in a small sphere most neutrons escape (k < 1), in a large one there are enough for a chain reaction. The sliders are the sphere radius and the enrichment. In the model a 90% uranium-235 sphere is critical at a radius of ≈ 9 cm (the Godiva assembly: 8.7 cm, 52 kg).
  • Nuclear reactor — fuel in water: on the light hydrogen nuclei the neutrons slow down to thermal ones (blue), which fission U-235 hundreds of times more readily than fast ones (white). Boron carbide rods absorb the extra neutrons and keep k ≈ 1; without water the reactor dies out. let in neutrons from the source gives starting neutrons.
  • Nuclear explosion — a supercritical assembly, k ≈ 2: the number of fissions doubles every generation (≈10 ns), the energy heats and pushes the metal apart, and the chain dies out before all the uranium has split; the energy is shown in joules and TNT equivalent.

Quarks

  • A quark and an antiquark interact through the Cornell potential V = σr − (4/3)αsħc/r (σ = 0.9 GeV/fm, αs = 0.3); the three quarks of a baryon are joined by a Y-shaped string through the Fermat point. The motion is relativistic, gluons repaint the quarks, but a hadron always stays colorless. The quarks are point-like, the balls are for clarity; time is in fm/c (3·10⁻²⁴ s).
  • Inside a proton (variant: a neutron): the proton mass of 938 MeV is mostly field energy, not the mass of the u and d themselves.
  • String breaking: the antiquark is pulled with a constant force; if it exceeds the string tension of 0.9 GeV/fm (≈15 tons), there is enough energy for a new quark–antiquark pair, and the string breaks — two mesons instead of a free quark. The plot shows V(r) and the current string length.
  • Proton collision: the quarks fly apart at nearly the speed of light, the strings break again and again, and the pieces become mesons (π, K) — hadron jets, as in the event generators of the Large Hadron Collider.
  • Hadron builder: the u, d, s, c, b buttons and the antiquarks — assemble a particle: three quarks make a baryon, a quark and an antiquark make a meson; the name, mass and spin come from the Particle Data Group tables. Colored combinations (one quark, two quarks) "do not exist".
  • Neutron decay from the inside: through the weak interaction a d quark turns into a u, emitting a W⁻ boson that at once decays into an electron and an antineutrino.

Semiconductors

  • A two-dimensional drift–diffusion model of the device: the Poisson equation for the potential and the continuity equations for electrons and holes (the Scharfetter–Gummel scheme), Shockley–Read–Hall and radiative recombination; silicon parameters at 300 K (μn = 1400, μp = 450 cm²/(V·s), nᵢ = 10¹⁰ cm⁻³). The dots are electrons (light blue) and holes (orange) in proportion to their concentrations, the background shows the dopant ions. Sizes are in micrometers, time in picoseconds.
  • Diode — a p–n junction: the depletion layer, the built-in potential; the anode voltage slider. The points of the current–voltage curve are added as you change the voltage; the forward current matches the Shockley formula.
  • LED and solar cell (choose the device in the panel): in a direct-gap semiconductor recombination gives photons of the band-gap color — red (AlGaInP), green or blue (InGaN); in a solar cell light creates pairs, the junction field separates them, and the cell delivers power.
  • MOSFET: a gate voltage above the threshold gathers a layer of electrons under the oxide — the channel; the drain current grows, and at large Vd the channel near the drain "pinches off" and the current saturates. Below — the band diagram along the channel.
  • Bipolar n–p–n transistor: the emitter injects electrons into the thin base, and almost all of them cross it to the collector; the base current is tens of times smaller than the collector current, and the gain β is in the readings.

Quantum waves

  • The electron wave function ψ(x, y, t) on a 256×256 grid — the Schrödinger equation is solved by the split-step method with fast Fourier transforms; units are nm, fs, eV. Brightness is the probability density |ψ|², color is the phase of ψ (the phase as color check box). A click on the wave is a position measurement: with probability |ψ|² the electron is found at that point and the wave collapses to it; otherwise the wave vanishes there.
  • Tunneling: a packet with energy below the barrier partly passes through it; the transmitted share is compared with plane-wave theory. The sliders are the electron energy and the barrier height and width.
  • Double slit: each electron hits the screen at one point, but together they draw interference fringes with the period λD/d; the detector at the slits learns the path of the electron — and the fringes disappear.
  • Quantum oscillator: a coherent state swings like a ball on a spring and does not spread; a squeezed one "breathes" at the frequency 2ω. The ⟨x⟩(t) plot is compared with the classical ball.
  • Quantum carpet: a packet in a box spreads, gathers into several copies at fractions of the period and revives completely after T = 4mL²/(πħ); the picture is |ψ(x, t)|²: the box horizontally, time from top to bottom.
  • Electron diffraction (Davisson and Germer, 1927): a crystal is a grating for de Broglie waves, and the beam leaves in rays at the angles d·sin θ = nλ; a plot of intensity by angle.

Periodic table

E (or Table in the top bar) — all 118 elements. Categories are told apart by gray level and the pattern of the strip at the top of each cell (solid, dashed, dotted); the legend below the table explains them, and radioactive elements carry a small triangle in the corner. Clicking selects the element: it becomes the first palette cell, and if a source field object is selected, it becomes the source's element.

Hovering shows the element card:

  • symbol, name, category, atomic mass, "radioactive"; a small colored square shows the atom's color in the scene;
  • electronegativity χ, valence, covalent radius r_cov (for metals also r_met);
  • group and period, or "period N · f-element" for lanthanides and actinides;
  • the ground-state electron configuration with a noble-gas core, e.g. [Ar] 3d⁶ 4s² for iron, including the known exceptions such as Cr [Ar] 3d⁵ 4s¹, Cu [Ar] 3d¹⁰ 4s¹, Pd [Kr] 4d¹⁰ and Au [Xe] 4f¹⁴ 5d¹⁰ 6s¹;
  • melting point and boiling point in °C; for C and As, which do not melt at 1 atm, the sublimation point;
  • density ρ in g/cm³ (for gases in g/L), ionization energy (the first one, eV) and the state at 20 °C (solid, liquid or gas);
  • how the element works in the model;
  • a thumbnail of the electron cloud; its button or F7 opens the atom structure.

Values for At, Fr and Z ≥ 99 are estimates and are shown with "≈". For Z ≥ 104 the card says the properties of the element are not measured: its atoms live seconds or less.

  • Noble gases — van der Waals only.
  • Metals — many-body metallic bonding; with non-metals they form ionic-covalent bonds (oxides, halides).
  • Non-metals — covalent bonds by Pauling's rules (the energy grows with the electronegativity difference), multiple bonds for B, C, N, O, Si, P, S, Ge, As, Se.
  • Radioactive elements are marked; they do not decay in the molecular dynamics — decay and fission are shown in the world of nuclei (the Nuclei section of the scene menu).

Files, snapshots, export

  • Saving (Ctrl+S, F5) — the whole state: atoms, bonds, pins, field objects, parameters, view. Older files still open.
  • Snapshot — F12: a PNG of the scene, next to atoms.exe or in Pictures\Atoms (see Settings); Shift+F12 — the whole window; Ctrl+F12 — record frames into a folder named frames_… (кадры_… with the Russian interface); you can assemble a video from it.
  • CSV — Ctrl+E: plots of T, P, energies, g(r), speed distribution, MSD and molecule counts, for Excel. With the English interface the separator is a comma and the decimal mark a point; with the Russian one — a semicolon and a comma.
  • atoms.ini next to atoms.exe stores the language and all settings; with “previous session” on startup, session.atoms keeps the state at exit.
